# post-api-plus

글·댓글 REST API를 만드는 부트캠프 과제입니다. 장희성 강사의 "스프링부트 REST API" 강의(14172) 방식을 따릅니다.

- **목표**: 완성된 소스코드를 내가 이해하는 것
- **진행 방식**: 새 개념 하나 = 커밋 하나. 커밋마다 같은 이름의 태그를 붙여, 태그 링크로 그 시점의 코드를 볼 수 있습니다.

## 과제 요구사항

- [ ] 프로젝트 새로 생성
- [ ] 글 3건, 댓글 5건 자동생성
- [ ] 글 작성 기능/테스트케이스
- [ ] 글 삭제 기능/테스트케이스
- [ ] 댓글 작성 기능/테스트케이스
- [ ] 댓글 삭제 기능/테스트케이스
- [ ] 리포지터리 제출
